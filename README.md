\# CipherVault 🔐



CipherVault is a desktop cybersecurity application for securely encrypting and decrypting text using modern cryptography.



\## Features



\- 🔐 AES-256-GCM encryption

\- 🔑 Password-based key derivation using PBKDF2-HMAC-SHA256

\- 📝 Text encryption and decryption

\- 📁 File encryption and decryption

\- 🖥️ Modern desktop GUI built with PySide6

\- 🛡️ Authenticated encryption for data integrity

\- 🎲 Random salt and nonce for every encryption operation



\## Technologies Used



\- Python

\- PySide6

\- Cryptography

\- AES-256-GCM

\- PBKDF2-HMAC-SHA256

\- Git \& GitHub
